> [!IMPORTANT]
> MECCHA CHAMELEON is a single-player arcade action game. All options are **client-side only** — no host guard needed.

## What it does

MECCHA CHAMELEON is a fast-paced platformer where you control a shape-shifting mech that changes form mid-air. You chain wall-jumps, dash through obstacles, and switch colors to match gates. One mistake resets the level, and combos are everything.

This trainer removes the reset. **Invincibility** lets you ignore hazards, **infinite lives** means you never restart from the beginning, and **super speed** turns the game into a blur. **Unlock all mechs** gives you every form and color from the start, and **max combo** keeps your score multiplier permanently high — great for speedruns or just seeing the later levels.

## Hotkeys

`Insert` opens the menu · `End` resets everything · `F1`–`F11` as above, all rebindable

> [!TIP]
> **Gravity reduction** + **infinite jumps** + **noclip** turns MECCHA CHAMELEON into a floating playground — explore levels from angles the devs never intended.

> [!WARNING]
> **Super speed above 5x** can break level triggers and collision detection. Save often.

## FAQ

<details>
<summary>Will this break my save file?</summary>
Unlocks write to your save. Make a backup if you're worried, but they're designed to be safe.
</details>

<details>
<summary>Does this work with achievements?</summary>
Yes — achievements will unlock normally if you meet conditions. Some may not trigger if you skip levels via unlocks.
</details>

<details>
<summary>Options stopped working after an update.</summary>
Game updates shift memory offsets. Check Releases for a matching build.
</details>
